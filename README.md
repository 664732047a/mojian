# 墨笺 · Mojian 1.1

[下载安装包](https://github.com/664732047a/mojian/releases/latest) · [查看源码](https://github.com/664732047a/mojian)

本次更新：普通代码块只显示一份可编辑内容；触摸板双指张开或合拢可缩放正文（60%–240%），点击底部百分比恢复 100%。缩放比例会记住。

左侧可以同时添加多个文件夹，点击文件夹后，下方只显示该文件夹的文件。数字显示包含子文件夹在内的文稿数量。点击下方的「+」可直接在当前文件夹创建文稿；先点击子文件夹再新建，则保存到该子文件夹。移除列表中的文件夹不会删除磁盘文件。

自动保存默认开启。第一次保存选好位置后，停止输入约两秒会自动保存；通过侧栏新建的文稿已确定保存位置，可以直接开始写。底部会显示自动保存状态。

从安装盘直接启动时，软件会询问是否安装到「应用程序」。安装后的版本会向 macOS 注册，以便在应用程序列表中找到。

一款在自己的 Mac 上使用的 Markdown 写作软件。即时渲染让标题、列表、表格和公式在写作时直接呈现；需要精确调整时，可以切换到 Markdown 源码。

## 安装

1. 双击交付的 `.dmg` 安装包。
2. 将「墨笺」拖到「Applications / 应用程序」文件夹。
3. 从「应用程序」打开「墨笺」。

这个版本供本机个人使用，未使用 Apple 开发者证书签名和公证。如果 macOS 提示无法验证开发者，确认安装包来自本项目后，在「系统设置 → 隐私与安全性」中查看并选择「仍要打开」。根据 macOS 版本，也可在「应用程序」里按住 Control 点按「墨笺」，选择「打开」。

## 开始写作

- 使用 `⌘N` 新建文档，`⌘O` 打开 Markdown 文件，`⌘S` 保存。
- 打开文件夹后，在左侧文件树里切换文档；标签页让多个文档保持打开。
- 在编辑器里直接输入 Markdown。输入 `# ` 开始一级标题，输入 `- ` 开始列表，输入三个反引号开始代码块。
- 工具栏可插入标题、粗体、斜体、链接、图片、引用、表格和代码块。
- 在「即时渲染」与「源码」之间切换，选择适合当前工作的方式。
- 文档大纲根据标题生成，点击标题可以跳转。
- 使用查找替换和命令面板快速操作。
- 可将文档导出为 HTML 或 PDF；Markdown 文件仍然是普通文本，方便其他软件继续使用。

## 写作偏好

在偏好设置里选择明亮、暗色或跟随系统主题，调整字号、行高和正文宽度。专注模式隐藏多余面板，打字机模式为当前段落保留更多空间。

已保存文档支持自动保存。首次写作时，请先保存并选择文件位置。恢复草稿用于尽可能保留意外退出前的编辑；重要文档仍建议配合 Time Machine 或其他备份工具。

每次覆盖保存前会保留上一版本；可在状态栏的历史按钮中查看并载入，确认后再保存。每份文稿最多保留最近 40 个历史版本。

插入图片时，图片会复制到文稿旁的 `assets` 文件夹。还没有保存的文稿会先使用本机附件目录；分享带图片的 Markdown 时，请带上对应附件。导出 HTML 会内嵌本地图片，方便独立分享。

常用快捷键：`⌘F` 查找，`⌘⌥F` 或 `⌘⇧H` 查找替换，`⌘⇧P` 命令面板，`⌘/` 切换源码，`⌘,` 偏好设置。

文档内容和设置保存在本机，不需要登录账号。图片、数学公式与流程图的依赖随安装包附带，核心写作功能可以离线使用。

## 功能范围

墨笺是独立开发的 Markdown 编辑器，不包含 Typora 的程序或商业资源，也不宣称与 Typora 的每一项行为完全相同。当前版本重点提供即时渲染、源码编辑、本地文件管理、标签页、自动保存与恢复、基础格式工具、搜索替换、主题、专注写作以及 HTML / PDF 导出。

以下能力目前未提供：Typora 主题文件的完全兼容、Pandoc 全格式导入导出、云同步与多人协作。特别复杂的 Markdown 扩展和排版，在其他软件中可能有不同显示效果。

## 本地开发与打包

需要 macOS、Node.js 22 或更新版本和可用的 Xcode 命令行工具。

```sh
npm install
npm run dev
```

生成生产版本和 DMG：

```sh
npm run build
npm run package
```

安装包默认面向 Apple 芯片 Mac，实际交付的文件名与版本号以 `release` 目录里的产物为准。

运行验证：

```sh
npm test
npm run test:app
npm run test:workspace
```

`test:app` 和 `test:workspace` 会启动独立的测试实例，使用临时文稿和设置，不会修改日常使用的文稿。安装包作为 GitHub Releases 附件提供；依赖目录、构建产物和本机测试记录不纳入源码仓库。

图标来自项目内原创矢量图形，可使用 `python3 scripts/create-icon.py` 重新生成。该命令需要 Pillow；打包时直接使用已经生成的图标即可。
